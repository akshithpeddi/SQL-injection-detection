# SQL-injection
# Real-Time SQL Injection Detection Using Machine Learning

MSc Computing dissertation project — University of Roehampton.

## Overview
A system that uses machine learning to detect and block SQL injection
attacks in real time, before they reach the database, and benchmarks it
against a rule-based firewall (ModSecurity).

## Research Question
Can a machine learning model detect SQL injection in real time more
accurately than a traditional rule-based firewall, while staying fast
enough to use live?

## Tech Stack
Python, scikit-learn, Flask, MySQL, sqlmap, ModSecurity, Docker

## Status
In development.
